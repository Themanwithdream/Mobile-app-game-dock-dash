DOCK DASH — CARGO WORLDS

The current game is index.html. App launch settings are manifest.webmanifest.
The icons folder contains 192px and 512px web icons, a maskable Android icon,
and a 180px iPhone Home Screen icon. Keep these files together when publishing.

New: 300 product parcels, a saved Cargo Collection, three logistics locations,
Tour mode, original synthesized music, separate effects controls and volume.
Open Routes & audio on the menu or pause screen to choose your preferences.
Use Cargo to browse items. Products never change the sorting colour or symbol.

After publishing on HTTPS, open the game in iPhone Safari and choose:
Share > Add to Home Screen > Open as Web App (if shown) > Add.

This version does not include a service worker for offline reopening.
See README.md for the complete feature list and validation.
