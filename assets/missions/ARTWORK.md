# Dock Dash mission artwork

Generated with the built-in image-generation tool in reference-image mode. The existing bundled warehouse floor was supplied as the visual style reference. No fallback CLI or external image API was used.

Final assets are `assets/missions/matchday.png`, `assets/missions/festival.png`, `assets/missions/rescue.png` and `assets/missions/space.png`. Each is a 360 × 640 opaque PNG. Generated source images were resized with nearest-neighbour sampling and saved as RGB PNGs with lossless compression. Product illustrations extend the game's original canvas icon system.
